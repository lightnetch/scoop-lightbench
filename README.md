# lightBench Scoop bucket

Official Scoop bucket for [lightBench](https://lightbench.ch), the free hardware benchmark for Windows, macOS and Linux.

## Install

```powershell
scoop bucket add lightbench https://github.com/lightnetch/scoop-lightbench
scoop install lightbench/lightbench
```

Then start the app with `lightbench` or run it in a terminal with `lightbench --cli`.

The manifest uses the signed, versioned release files published by lightnet multimedia gmbh on `lightbench.ch`.
